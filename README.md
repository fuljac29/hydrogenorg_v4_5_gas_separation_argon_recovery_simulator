# HydrogenOrg V4.5 — Gas Separation & Argon Recovery Simulator

Integrated Engineering Phase — Module 5.

This conceptual simulator connects the V4.4 plasma reactor outlet to gas separation and Argon recirculation.

It calculates separated H2/O2, purity signals, residual water condensation, Argon recovery, leakage and makeup demand, Argon cost, separation energy, purge readiness, gas quality and safety score.

## Run locally

```powershell
pip install -r requirements.txt
streamlit run app.py
```
